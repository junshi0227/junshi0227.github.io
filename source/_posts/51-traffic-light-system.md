学习51单片机时，我选择了《单片机原理及应用》期末作业的限选题目C“基于单片机的交通灯显示系统”，并用开发板、面包板上的信号灯和LCD1602完成了实物演示。这个项目把LED输出、字符屏显示和独立按键输入放进同一个控制流程。

## 题目要求与我的实现

课程文件允许软件仿真或硬件实现。题目C要求东西、南北方向各有红黄绿三种信号灯；按下紧急按钮后所有方向亮红灯，再次按下恢复正常显示；夜间模式下所有方向黄灯闪烁；还要实时提醒绿灯剩余时间，并留有自选创新内容。

| 课程要求 | 项目中的做法 |
| --- | --- |
| 双向三色信号灯 | 用两组红、黄、绿LED表示南北与东西方向，按倒计时切换状态 |
| 紧急全红及恢复 | 按键切换紧急模式，LCD1602显示`Emergency Mode`，再次按键返回普通状态 |
| 夜间黄灯闪烁 | 按键切换夜间模式，两方向黄灯闪烁，屏幕显示`Night Mode` |
| 绿灯剩余时间提醒 | 屏幕显示当前方向与灯色的倒计时；绿灯亮时可直接看到剩余秒数 |
| 自选创新内容 | 扩展显示双向灯色与剩余时间，并通过按键手动调整放行配时 |

## 从固定配时开始

项目使用KeilµVision的MCS-51工程，目标器件设置为AT89C52。程序将南北和东西方向分别抽象为红、黄、绿三种状态，用端口电平控制对应的LED。普通模式从“南北绿灯、东西红灯”开始，按倒计时推进灯色；源码中默认绿灯为5秒、黄灯为3秒，红灯初始值为8秒。

LCD1602的两行分别显示南北方向和东西方向的当前灯色与剩余秒数。题目只要求提醒绿灯亮的剩余时间，我把显示扩展到了红、黄、绿各阶段，便于直接检查两个方向的状态。

## 按键控制的两个扩展

一组按键用于切换运行模式：夜间模式让两方向黄灯闪烁；紧急模式让两方向红灯常亮，再次按下紧急按钮返回普通显示。在灯光更新逻辑里，紧急模式的判断排在夜间模式之前，体现了紧急状态优先处理的设计。

另外两个按键用于调整配时。源码通过一个增减量改变南北方向的绿灯时长，并相应调整东西方向的绿灯与两方向的红灯时长。这样可以手动模拟车流量不均时的放行时间分配。地感线圈或视觉检测车流量是项目说明中提出的后续设想，当前版本仍由按键调节。

## 演示视频里能看到什么

视频中，普通模式下两组红黄绿LED随状态变化，LCD1602同时显示`NS Green`、`EW Red`等方向与灯色，以及各自的倒计时。按下模式按键后，屏幕依次出现`Night Mode / Yellow Blinking`和`Emergency Mode / Red always on`提示；画面中也能看到夜间模式的黄灯与紧急模式的红灯。视频后段还演示了通过按键改变倒计时数值。

## 复盘

这个小项目让我把GPIO控制、字符屏显示和状态切换串成了完整流程。回看工程文件，也能看到进一步完善的地方：按键读取缺少明确的消抖与调时边界限制；保存的构建日志还提示主函数调用倒计时函数时少传了一个参数。因此，项目适合作为课程学习记录，不能直接当作可用于真实路口的控制器。
